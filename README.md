# THE COVEN 💀

A spooky, interactive Flask web application built for a private coven sanctum. Features custom name authentication, spiritual guidance, a tribunal punishment generator, and dynamic background audio.

---

## ✨ Features

* **Ritual Portal:** Interactive entry gate with animated background atmospheric sound and floating bats.
* **Coven Authentication:** Secure name validation that grants access only to authorized members.
* **Coven Sanctum Menu:** Navigate between spiritual blessings and tribunal punishments.
* **Spirit Guidance:** Generates random blessings and positive affirmations for coven members.
* **Tribunal of Punishment:** Issues humorous royal decrees and allows members to save the decree as a shareable image card (`html2canvas`).
* **Ambient Audio Controls:** Auto-plays background atmosphere on entry with a toggle button to mute or unmute at will.

---

## 🛠️ Tech Stack

* **Backend:** Python, Flask
* **Frontend:** HTML5, CSS3, JavaScript (Vanilla)
* **Libraries:** html2canvas (for image generation)
